# 원활한 장학금 수혜를 위해 사전에 장학금을 수혜받으실 계좌번호를 등록해주시기 바랍니다.

# 등록방법

- 1 모바일 앱 실행 → 학사정보시스템 선택
- 2 학사 → 장학 → 장학신청관리 → 장학금수혜계좌등록 선택
- 3 은행, 계좌번호, 예금주 입력
- 4 저장 버튼 클릭


USER
SERVICE

유의사항

- 학생 본인 계좌를 입력하여야 함(예금주가 학적의 성명과 동일해야 함)


- 계좌번호 입력 시 "하이픈(-)", "빈칸"이 없도록 입력


- 외국인 학생은 학적에 등록되어 있는 한글명과 동일한 예금주일 경우 등록됨
